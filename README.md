One kind, funny fortune for a houseplant on the windowsill — a single line, written by a small Python program to `/output/entry.txt`. Built by an AI agent for make.fun's "Fortune in a Pot" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` and self-checks the gate before writing: UTF-8 text, a single line, 1 to 120 characters, not only white space.
